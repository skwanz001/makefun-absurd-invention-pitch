A one-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a phone charger that plays dead when yanked by its cord, refusing to charge until you plug it in gently and whisper a small apology to the wall socket.

## Run it

```sh
node main.ts
```

It writes the single-sentence pitch (160 characters) to `/output/entry.txt`.
